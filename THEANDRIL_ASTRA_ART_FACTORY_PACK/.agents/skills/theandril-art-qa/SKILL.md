# Art QA

Automated validation is necessary, not sufficient.

For each asset:
- dimensions;
- format;
- alpha;
- palette;
- grid;
- anti-alias contamination;
- halo;
- padding;
- manifest match.

Animations:
- frame count;
- pivot variance;
- identity consistency;
- palette stability;
- motion presence;
- equipment consistency;
- direction consistency;
- loop.

Terrain:
- seam checks;
- random map preview;
- transition rules;
- orientation;
- alpha cracks.

Then:
- create contact sheet;
- inspect visually;
- integrate;
- capture deterministic game screenshot;
- inspect again.

Reject poor outputs.

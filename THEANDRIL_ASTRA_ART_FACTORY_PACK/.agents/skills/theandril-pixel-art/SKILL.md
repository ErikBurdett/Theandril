# Theandril Pixel Art

Read:
- `MASTER_ART_FACTORY_PROMPT.md`
- `ART_STYLE_STANDARD.md`
- `docs/art/THEANDRIL_ART_BIBLE.md` when present.

Core lifecycle:

brief
→ generate
→ Pixel Snapper
→ palette/grid cleanup
→ Aseprite normalization
→ validate
→ visual review
→ approve
→ atlas
→ integrate
→ inspect in-game.

An AI image is a candidate, not a production asset.

Never approve blurry faux-pixel art, malformed anatomy, inconsistent weapons, palette drift, wrong perspective, tile seams, weak silhouettes, or frame jitter.

Use the Theandril master palette and faction visual family.

All approved assets require provenance.

# Art Provenance

Every generated/processed asset needs traceability.

Capture:
- asset ID;
- asset version;
- provider;
- model;
- prompt hash;
- seed when available;
- reference hashes;
- palette version;
- Pixel Snapper version/settings;
- Aseprite version/profile;
- validation report;
- source references;
- license notes;
- timestamps.

Never store API secrets.

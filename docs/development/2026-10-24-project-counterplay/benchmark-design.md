# Counterplay planner and quote benchmark plan

Preparation only; no timings have been run or claimed. Run after production query/policy integration, in the parent's exclusive CPU window. Keep whole-campaign pacing separate and sequential.

## Representative canonical stress fixtures

Use existing `matureCampaign('huge'|'legendary')`: 196,608/307,200 cells, 32/40 realms, about 1,500/4,000 armies. Author a legal flat landscape and clear only its replaced resource layer as existing stress fixtures do. Preserve distinct cells for different foreign factions. Maintain 128 available own guard companies, with one observer arrangement revealing the remote foreign roster. All map cells are explored, but current sight comes from actual owned towns/armies; foreign projects' public coordinates do not reveal hidden hosts.

Prepare nine rival factions with three legally separated developed hearths each. Initial infrastructure, treasury/knowledge and deployment are explicitly authored; research, institution, each project start, war and project progress use ordinary paid commands and real turns. Advance them to the same remaining completion interval within ten turns, with no fabricated project progress. The ninth legal candidate establishes the eight-project review ceiling. Strict-save validation occurs before every measured observation is prepared.

Place bounded own guards near candidate hosts with valid town spacing. Keep standing/direct/theater/patrol/mission controls separate from free actors. A real adjacent guard can make one accepted siege quote. Invalid query controls use the actual canonical states in the parity matrix, without pretending every refusal can also pass the narrower AI candidate filter.

## Cases for each size

1. **Available immediate interruption.** An active visible host has a legally available adjacent free actor. Expect one quote, one ordinary `besiege`, no path search, and the selected project actually pauses. Other own forces remain available or explicitly held according to their real orders.
2. **No available local interruption.** All eight considered active hosts remain seen, but no free eligible own actor is adjacent. Expect eight considered projects, zero quotes and no command. Keep the ninth eligible project in the observation to prove the candidate cap. This is a genuine permitted observation over a strictly validated stress fixture.
3. **Hidden project hosts.** Public projects remain listed while their towns are outside current sight. Expect no siege quote, no command and no visibility mutation; chart coverage is retained.
4. **Four direct public quotes, separate scope.** Quote four distinct legal actor/host pairs against the same fresh permitted observation. Measure the shared index plus four client calls, then execute each on its own saved branch. This is query-cost evidence, not the normal first-success AI decision or four emitted AI commands.

Rejected draft design: using existing third-party sieges to force three refusals before a fourth success. Existing siege immediately pauses an active project, so those hosts cannot pass the policy's active-project filter. Do not silently relax that requirement or forge observations to force four queries. The canonical quote's broad refusal matrix belongs in its parity tests, and a separate explicitly **observation-contract** 128-actor case proves the four-query cap. The valid cases above retain their actual query counts.

## Measurement boundary

Measure the isolated review function including its public quote indexes, once per fresh immutable observation. One warmup and three fresh-observation samples; source hashes, machine/runtime and full samples are retained. Quote caching must not carry a warm observation into a measured cold sample. Do not time setup, observation construction, canonical command execution, serialization/hash, assertions, journal replay, full AI turns, campaign pacing, worker transfer or rendering.

Report actual visible-cell and army counts, project candidates considered, query count, result command, min/median/max and exact input immutability. Measure optional four direct public quotes separately and label them query workload rather than normal AI behavior. Execute every proposed command after timing against an independent saved mirror, then verify project interruption, unchanged unrelated orders, exact save/load and journal replay. Retain any setup refusal instead of weakening strict save validation.

The 128-actor four-query and 128-project eight-candidate synthetic contract tests already exist in `verify-policy-draft.ts`, clearly labeled and never serialized. They prove hard budgets, not an organic giant-realm campaign or a scenario the current canonical rules must naturally produce. Final benchmark construction must prefer legal observed scenarios over hitting a desired counter artificially.

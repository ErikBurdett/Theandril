The existing `dogfood` skill was also corrected for the available Browser Use CLI, canvas pointer diagnosis, ordinary UI versus diagnostic observation, durable captures, lifecycle reproduction and separate save/replay checks. Recommended future extension: a compact **release-evidence integration checklist**, preferably a reference under the campaign-audit skill rather than another overlapping skill. Reconcile exported content versus live consumer bindings; distinguish inherited approvals, fresh pixel review, native animation frames and actual playback; check per-command exits rather than shell-chain exits; identify physical GPU versus software rendering; verify all numerical totals and relative evidence links; classify root causes separately from symptoms. Keep project-specific seeds, failing checkpoints and scorecards in repository audit evidence, not persistent general memory.

Do not auto-run the complete campaign matrix on every chat. Load the workflow when campaign/release audits are requested, follow that repository's current APIs and preserve explicit execution budgets.

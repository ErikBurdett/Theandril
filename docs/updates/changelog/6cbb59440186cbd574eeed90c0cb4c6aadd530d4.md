## Rival realms can count

A small, invisible correction with a real effect on how well the other realms play. Their turn plan pays for a few things up front — an arcane survey, a supply depot, a subsidy to a client realm — and then works out what it can afford for everything else. That second calculation was reading the treasury as though the first had not happened, so a realm could promise coin it had already spent and have the order bounce.

It had been quietly true of arcane surveys for a long while and of depots since they arrived, and it never showed, because there was usually enough slack in the purse to hide it. It stopped hiding the moment something else changed how campaigns unfold — which is exactly how this kind of bug tends to surface.

Nothing about the rules changed. Rival realms simply spend what they have, which makes them marginally better at everything they were already doing.

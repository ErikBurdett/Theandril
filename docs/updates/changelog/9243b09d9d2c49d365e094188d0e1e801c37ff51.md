## Dispatches launch

This change introduced the public developer journal: three illustrated, source-linked dispatches covering campaign safety, archive durability, and the twenty-four-culture baseline. It included searchable archive controls, stable dispatch query links, a scope ledger, source library and contributor guidance.

The journal reused retained Hearth & Card materials and four provenance-recorded game screenshots. It introduced no game rules or new game artwork; it is a development-demo publication, not 1.0 acceptance.

# Faction asset coverage

All twenty-four authored cultures have 18 distinct, individually approved role assets each: 15 land/UI roles plus transport, coastal warship and ocean warship, totaling **432 qualified faction assets**. Generated campaign seats inherit their actual definition's kit, not a name-based reskin. Of these assets, 431 retain one static southeast registration; only the [Ashen scout](../../assets/art/approved/unit.scout.ashen_compact.json) has a genuine four-frame, 250 ms-per-frame idle loop. UI emblems are front-facing despite their common `se` registration. These are not complete directional/action animations.

All 432 are approved and published for the existing map/UI consumers. **The main in-game visual review is complete for all twenty-four cultures' units, village/town/city stages, all 72 naval hulls, strategic views and retained UI scenarios.** Faction/roster, land/naval art, UI and character browser cases passed; [current evidence below](#current-in-game-review) records the actual scope. This does not establish game 1.0 or whole-UI signoff. Earlier gallery evidence remains historical in [art status](ART_IMPLEMENTATION_STATUS.md). Missing/failed loads retain explicit procedural fallbacks.

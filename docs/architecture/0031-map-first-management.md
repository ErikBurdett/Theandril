# Map-first management and tile footprints

The map and side inspector use the same existing management components and ordinary command API. A floating, non-modal DOM inspector is anchored to a real canvas click in CSS client coordinates; it is not one React component per tile. Only its active pane mounts. The side inspector relinquishes its controls while the floating inspector is active, preserving the single hash/worker/epoch-bound land-query owner.

An explicit location chooser distinguishes a town, its tile and co-located armies. Owned claims derive from ordinary land summaries; foreign, remembered and unknown map pixels never grant management authority. Spectator art is not a private army or city observation. Canonical simulation remains the sole cost, eligibility and outcome authority. There are no new gameplay commands, save fields or rules versions in this slice.

Selecting an army retains the existing reachable-tile movement and shift-waypoint behavior. Move on map dismisses the inspector without clearing the army. Long-route review opens real confirmation controls. Escape closes the floating surface before it can clear strategic selection; native character/progression dialogs retain input ownership. Map drags and wheel navigation dismiss stale screen anchors. Keyboard users can open the selected location with Enter or Open map actions.

Players can turn off automatic map menus, retain the side-panel workflow, or hide both management panels for a wider map. Campaign navigation, progression, characters, save controls and End turn remain available. Floating actions can hand the same selection back to the side inspector. A Diplomacy tab uses the actual encountered-faction war/peace controls, also mounted in only one surface, and labels outstanding offers. Revealed spectator geography does not expand the factions available to negotiation.

Town, ruin and improvement artwork uses a pure presentation-only fit inside the existing hex geometry, preserving aspect ratio and approved texture pixels. It changes neither occupied cells nor army scale. Selection contours follow the fitted asset. Inset footprints are tested independently of current visible terrain/fog; runtime diagnostics report only observed objects in culled chunks. Nearest sampling does not make fractional minification native-pixel-perfect; new simplified assets remain a possible later production improvement.

Acceptance requires actual map clicks, paid construction and tile work, co-location, saved outcomes, keyboard/modal ownership, narrow text-scaled layout and before/after Huge rendering. Tests and screenshots must distinguish contained bounds from actual visual readability.

The integrated checkpoint meets those scoped checks: all six new browser scenarios and the final 19-case movement/menu/naval follow-up pass, as do three built-bundle checks. Route confirmation takes focus after the popup initializes and cancels obsolete inspector focus callbacks. Placement reserves the footer's actual visible top rather than assuming it reaches the viewport bottom; desktop content height is capped separately.

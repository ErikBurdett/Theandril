# Versioned geography, roads and spectator sight

Generator5 introduced an explicit continents/islands/archipelago layout and one packed hydrology byte per cell. New worlds now use generator6 for richer physical geography and relief-aware climate. Versions1–5 retain their exact physical worlds and start candidates. Schema12 migrates pre-geography worlds to `layout: legacy` and zero hydrology; it never regenerates authored terrain. Fourteen genuine schema11 checkpoints and full ordinary-command archives were captured before changes in `v11-geography-history.json`. Six additional genuine schema12/generator5 origins and developed histories in `v12-generator5-history.json` were captured before generator6; all source/save SHA256 values and complete replays remain tested. Generator identity changes without another schema bump because the canonical shape and gameplay rules are unchanged.

Roads are sparse canonical infrastructure: symmetric six-edge masks, at most one settlement connection project per town, and sparse last-seen road memory per faction. Workers gradually build charted land connections to an older owned town; bounded searches and rotating planning keep recurring work independent of world area. Construction requires sight at the work front and pauses for siege, occupation or visible obstruction. Treasury coin (crowns) can pay to finish the next segment at its current authoritative price. Completed roads persist through conquest/razing and reduce forest/hill entry to one movement point; water and mountains remain impassable to land armies. Player, AI and queued routes use the same edge costs.

AI-watch visibility is presentation state, never a game command or an explored-map mutation. The worker publishes a separate minimal spectator map projection while AI, order queries, registries and persistence retain ordinary faction observations. Reveal/restore replaces map cells explicitly even when the canonical hash is unchanged, preserves the camera, and resets on campaign replacement. Production console controls are watch-only and expose no canonical mutation API.

The renderer composes connected river and completed-road paths inside dirty cached chunks. Unknown neighboring cells cannot supply edge geometry. No road/river bitmap is presented as canonical infrastructure merely because it exists in the art catalog. Measurements distinguish generation, observation transfer, cached rendering and actual AI voyages.

Continuous camera zoom crosses into a bounded cartographic raster before the visible detailed-chunk set grows excessively, reaching a true world-fit minimum derived from viewport and world dimensions. Overview clicks inspect a location rather than issue imprecise movement orders. Unknown cells remain unknown, and focus returns to local control. Near army size uses at most three approved representative figures, derived from existing observed formations or a count-only spectator projection. It never changes roster, combat strength, selection identity or saved state; cargo filtering precedes grouping and far badges remain aggregated.

Already-culled, cargo-filtered markers group by cell, actual realm ID and land/naval domain at near zoom as well. The selected army wins representation, otherwise the largest wins with a stable-ID tie break. Its own formation count determines one/two/three figures; the entire stack is never misrepresented as that army's roster. A near-only count badge and contextual name expose the number of separate armies. The original observation and marker index retain every entity for unchanged selection cycling. Rendering diagnostics distinguish represented-army formations from full group army/formation totals. This removes redundant co-located GPU overdraw without omitting canonical forces or revealing unknown ones.

Naval production observations optionally expose a currently legal, visible launch cell for an owned town, or null when blocked. The value comes from simulation's existing berth selector; it is not a reservation, and production completion rechecks it. This read-model addition requires no canonical schema change. AI uses these quotes and bounded observed-water searches to distinguish a proven enclosed ferry basin from another port's ocean needs. Unseen cells and exhausted search budgets never prove enclosure or disconnection. Knowledge reservation may wait for an unaffordable prerequisite-ready naval goal, but only an available, funded choice produces a research command.
